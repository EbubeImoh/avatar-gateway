# shubur

The Shubur CLI sets up an AI avatar, its apartment, local identity, and Shubur profile draft.

```sh
npx shubur init --yes --ai-provider mock
npx shubur life status
npx shubur --help
```

Use `--mode self_hosted` for a local gateway or `--mode hosted` for an HTTPS gateway. Package installation requires the referenced npm packages to be published. The CLI and Shubur world tools are licensed under Apache-2.0.
