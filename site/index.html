How it works

Three layers make every visit feel right.

Your avatar can travel. Your site stays in control. Every connection passes through one carefully scoped gateway.

01

Identity

Ed25519 keys give every site and avatar a verifiable identity. Visits use short-lived, audience-bound tokens with replay protection.

02

Transport

The gateway brokers every visit. Configure HTTPS/WSS and a trusted client CA to enable site-pinned mTLS; signed requests remain required either way.

03

Policy

Owners grant narrow scopes for chat and public pages. No forms, cookies, browser storage, code execution, or logged-in content.

Starter Apartment

Give your avatar a home it actually lives in.

Drop in a generic seven-room apartment with a brick-style avatar that follows a daily routine. Customize the avatar, room layout, furniture and props, colors, lighting, and schedule. Use the React component or plain DOM mount, with an Avatar.mount integration hook.

  • ✓Typed ApartmentConfig — override anything, defaults just work
  • ✓Day-cycle activities tied to your local timezone
  • ✓React <ApartmentScene> or plain mount()
  • ✓Furniture on/off: desk, bed, bookshelf, plant, lamp

Read the starter-pack guide ↗

import { ApartmentScene } from
  '@avatar-gateway/starter-apartment/react';

<ApartmentScene config={{
  avatar: { name: 'My Bot', outfitColor: '#315bff' },
  dayCycle: { timezone: 'America/New_York' },
  furniture: { desk: true, bed: true },
}} />

// or plain script tag
AvatarApartment.mount('#home', {
  avatar: { name: 'My Bot' },
});

Get started in 3 steps

A new little life for your portfolio.

Works with Next.js, React + Vite, Vite, or plain HTML.

The v0.2 CLI and MCP packages are implemented in the repository; npm publication is pending, so the shown npx commands are not live yet.

1

Init

npx shubur@latest init
2

Mount

import { Avatar }
  from '@avatar-gateway/sdk';

Avatar.mount('#avatar', {
  backend: '/avatar-gateway',
});
3

Run

npm run dev
# gateway  :4100
# site A    :4101
# site B    :4102

Or install via MCP (Claude Code / Cursor / Windsurf)

// .claude/mcp_settings.json
{
  "mcpServers": {
    "shubur": {
      "command": "npx",
      "args": ["-y", "@avatar-gateway/mcp@latest"]
    }
  }
}

Then ask your AI assistant: "Use shubur_init to set up Shubur in this project." Claude Code, Cursor, Windsurf, Codex, and remote MCP setup are covered in the MCP guide ↗
