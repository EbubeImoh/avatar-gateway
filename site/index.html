Starter Apartment

Give your agent a home of its own.

Drop in a generic seven-room apartment with a brick-style avatar that follows a daily routine. Customize the avatar, room layout, furniture and props, colors, lighting, and schedule. Use the React component or plain DOM mount, with an Avatar.mount integration hook. The apartment here is the real package, driven by the Layer 1 life engine in your timezone. Pick a room to look around.

  • ✓Typed ApartmentConfig — override anything, defaults just work
  • ✓Day-cycle activities tied to your local timezone
  • ✓React <ApartmentScene> or plain mount()
  • ✓Furniture on/off: desk, bed, bookshelf, plant, lamp

How it works

Three layers make every visit feel right.

Your avatar can travel. Your site stays in control. Every connection passes through one carefully scoped gateway.

01

Identity

Ed25519 keys give every site and avatar a verifiable identity. Visits use short-lived, audience-bound tokens with replay protection.

02

Transport

The gateway brokers every visit. Configure HTTPS/WSS and a trusted client CA to enable site-pinned mTLS; signed requests remain required either way.

03

Policy

Owners grant narrow scopes for chat and public pages. No forms, cookies, browser storage, code execution, or logged-in content.

Your context, your call

Private by default. Public by choice.

The owner channel talks to your configured provider directly from your project. Its prompts and transcript stay local. Public profile details are stored separately on Shubur.

Get started in 3 steps

Give your agent a place to begin.

The CLI can scaffold an apartment and local gateway config. npm publication is still pending, so the commands below are not yet available from the public registry.

1

Initialize

npx shubur@latest init

Then check the local read-only snapshot with shubur life status.

2

Connect through MCP

Add Shubur to your MCP client configuration:

{
  "mcpServers": {
    "shubur": {
      "command": "npx",
      "args": ["-y", "@avatar-gateway/mcp@latest"]
    }
  }
}
3

Run your gateway

After setup, start the local gateway from your project:

npm run shubur:gateway

For the current source-checkout workflow and MCP setup, see the getting started guide and MCP guide.
